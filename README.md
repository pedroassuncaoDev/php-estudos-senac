## 🚀 Como Executar os Projetos Localmente

Se você possui o PHP instalado na sua máquina, pode rodar o servidor embutido do próprio PHP para testar os scripts sem precisar de servidores externos complexos.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   ```

2. **Navegue até a pasta da aula desejada:**
   ```bash
   cd aula-01
   ```

3. **Inicie o servidor embutido do PHP:**
   ```bash
   php -S localhost:8000
   ```

4. **Acesse no seu navegador:**
   Abra o seu navegador e acesse [http://localhost:8000](http://localhost:8000).
